Every blog starts somewhere. This one starts with a note about why I'd rather write long-form than keep everything compressed into a LinkedIn post.

---

I've been meaning to do this for a while. There's a particular kind of thinking that only happens when you're forced to write it out. Not summarise but actually write. Put the argument in a sequence, check that it holds together, notice where you're hand-waving.

LinkedIn posts don't do that. They're too short to be wrong in interesting ways, and the format punishes density. Everything has to end with a call-to-action or a hot take. I don't always have a hot take. Sometimes I just have a thing I worked through and want to write down while it's still fresh.

So: blog.

---

## What I'll write about

Mostly things I'm working on or thinking through:

- AI/ML - not takes on the latest model, but implementation notes and things that surprised me while building
- Tools and workflow - how I set things up, what broke, what I changed
- Occasional longer notes on things I read or watched that were worth sitting with
- Any new game I start/finish playing


No posting schedule. I'll write when I have something worth saying.

---

This site is pure HTML and CSS with no framework. The blog works the same way, each post is a plain Markdown file fetched and rendered client-side. Simple as I can make it.
